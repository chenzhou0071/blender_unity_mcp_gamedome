## 2. 验收项（试玩全部通过）

1. 第三人称移动/转向/跳跃；**Shift 疾跑**（6→8，依反馈提速）
2. **攀爬**：贴台前推触发 → 自动爬升 → **到顶自动翻越站上台面**（Play 自动化实测：终点 (0,3.02,16.32)，isGrounded=True）
3. **机关链**：推块上压力板 → 石门升起；推块离开 → 关闭
4. 玩家站板同样触发（位置检测补偿：CC 不产生 Trigger 事件）
5. **终点**：上台走到祭坛旁 → “探索完成！你取得了圣物”（Play 实测：距离 1.006 < 1.5 触发）
6. 相机：鼠标环绕 + SphereCast 防穿墙；编辑态初始机位正常预览（(0,3.2,-7.3)）

## 3. 试玩反馈修复记录（5 轮）

1. “房间悬空” → 加 40×50 外部大地坪（顶面 -0.02 防共面闪烁）
2. “墙没贴住地面” → 墙底整体下沉 0.3m 埋入地面，物理上无缝隙
3. “墙悬空/Game 视图怪异” → 主相机初始机位 (0,0,0)→(0,3.2,-7.3)（消除贴地掠射伪透视）
4. **“墙的 y 轴太高”（真根因）** → 7 面墙位置 y 误用全高常量 `L2()`（6/6.3）而非半高 `WallH2()`（2.85），底部悬空 3m；逐面修正并**全量验证 9 面墙落地**（教训：验证不可只抽查）
5. 试玩反馈一次修复：Shift 提速；攀爬翻越 3 处根因（触发高度/贴墙吸附/翻越终点）；祭坛+宝物移至台顶；**GoalTrigger 与压力板改玩家位置检测**（原 OnTriggerEnter 对 CC 玩家永不触发）

## 4. 关键教训（M3 沿用）

- 构建器代码中“位置/尺寸”参数必须分离核对；自动化验证要**全量逐对象**，禁止单点抽查
- **CharacterController 玩家不触发 Trigger 事件**——玩家交互一律用位置/距离检测
- 攀爬翻越触发点应基于身高（头顶越过台顶），翻越终点必须落在**射线探测到的真实台面**上
- 编辑态 Game 视图相机不应停在 (0,0,0)（与地板共面产生掠射伪透视）
